# Healthcare-Admissions-and-Billing-Analysis
An Excel-based healthcare analytics project analyzing 55,000 patient admission records to identify patterns in patient demographics, medical conditions, admission types, insurance providers, billing, test results, and admission trends through an interactive dashboard. 
The project includes data cleaning and transformation, calculated fields, PivotTables, KPI analysis, interactive slicers, and an interactive Excel dashboard. Key findings and business implications are documented based on the analysis.
